# Assignment #2 - Advanced CSS (Flexbox & Grid)

**Student:** Melis Anel
**Group:** SE-2527

## Description

This project is Assignment #2 for Web Technologies.
The main goal of this assignment is to practice modern CSS layout techniques using **Flexbox** and **CSS Grid**.

The project contains five tasks. Each task demonstrates a different use of Flexbox, Grid, or both.

## Tasks

### Task 0 - Navigation Bar

A simple navigation bar created using Flexbox.

* Logo on the left
* Navigation links on the right
* Horizontal alignment
* Spacing between links
* Vertical alignment

### Task 1 - Card Row

A row of three cat cards created using Flexbox.

Each card contains:

* Image
* Title
* Description
* Button

The cards have equal height, consistent spacing, and a hover effect.

### Task 2 - Page Layout with Grid Areas

A page layout created using CSS Grid.

It contains:

* Header
* Sidebar
* Main content
* Footer

Grid areas are used to organize the page structure.

### Task 3 - Image Gallery

A cat image gallery created using CSS Grid.

The gallery contains nine images arranged in equal rows and columns. Each image has a caption that appears when the user hovers over it.

### Task 4 - Portfolio Page

A portfolio page combining Flexbox and CSS Grid.

It contains:

* Header with a Flexbox navigation bar
* Projects section
* Information sidebar
* Footer

The main section uses CSS Grid, while Flexbox is also used inside the project cards.

## Technologies
